# Security policy

## Supported version

Security fixes are applied to the latest revision of the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository's
[private vulnerability reporting](https://github.com/MehdiHellall/ebpf-ransom-lab/security/advisories/new)
form and include the affected revision, reproduction steps, impact, and any
suggested mitigation.

This project is a local research prototype. Reports about privilege boundaries,
collector input validation, artifact integrity, workload containment, and the
localhost dashboard are in scope.
